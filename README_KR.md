- 거래 자금 묶임

### Q. 왜 30초 주기인가?

- 시장 반응 최소화
- 거래 비용 최소화

### Q. 손실이 나면 어떻게 하나?
**A.** 자동 손절 매커니즘:
- -2~3% 손절 자동 실행

- 일일 손실 -10% 도달 시 중단
