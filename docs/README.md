# AI Investment Operating System Documentation

Version: 0.5.5
Status: Phase 5 Read-Only Evidence Started
Last Updated: 2026-07-28

## Purpose

This folder contains the official documentation set for the AI Investment Operating System.

All AI agents, including Codex and Claude Code, must treat these documents as the primary source of truth when reviewing, planning, or implementing the system.

1. [01_Project_Vision.md](01_Project_Vision.md) - project goals, philosophy, scope, and success criteria
2. [02_System_Architecture.md](02_System_Architecture.md) - full system architecture and component boundaries
3. [03_Domain_Model.md](03_Domain_Model.md) - domain entities, value objects, aggregates, and domain events
4. [04_Database_Architecture.md](04_Database_Architecture.md) - database design, schema, indexing, audit, and history
5. [05_API_Architecture.md](05_API_Architecture.md) - Toss Securities, Naver News, Claude, and internal API contracts
6. [06_AI_Architecture.md](06_AI_Architecture.md) - Claude usage, AI health checks, continuous learning, and strategy research
7. [07_Trading_System.md](07_Trading_System.md) - trading, order approval, risk, portfolio, and money management systems
8. [08_Testing_Validation.md](08_Testing_Validation.md) - unit, integration, backtest, paper trading, and validation strategy
9. [09_Operation_Deployment.md](09_Operation_Deployment.md) - production operations, monitoring, alerting, security, and recovery
10. [10_Claude_Code_Guide.md](10_Claude_Code_Guide.md) - implementation guide and task structure for Claude Code
11. [11_AI_RULES.md](11_AI_RULES.md) - non-negotiable safety and behavior rules for AI agents
12. [12_CHANGELOG.md](12_CHANGELOG.md) - documentation and architecture change history

14. [99_Development_Roadmap.md](99_Development_Roadmap.md) - phased development roadmap from documentation review through production hardening
15. [open_questions.md](open_questions.md) - unresolved architecture and implementation questions that must be tracked before task generation
